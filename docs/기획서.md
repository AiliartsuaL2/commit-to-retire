# 커밋에서 은퇴까지 — 기획서 v0.2

> 신입부터 은퇴까지, 한국 개발자의 커리어를 1년 단위로 살아보는 풍자 육성 게임.
> 서버 없이 브라우저에서 동작. 한 판 10~15분.

## 1. 확정된 방향

| 항목 | 결정 |
|---|---|
| 톤 | 현실 풍자 (야근, 레거시, 블라인드 드립) |
| 플레이 길이 | 10~15분 / 1턴 = 1년 / 약 25~35턴 |
| 고유명사 | 패러디 이름 (실명 사용 안 함) |
| 엔딩 평가 | 최고 직책·명성 + 업적 수집 |
| 제목 | **커밋에서 은퇴까지** |
| 캐릭터 그림 | 이모지·아이콘만 (재미가 검증되면 도트로 교체 검토) |
| 개인 생활 | 가볍게 — 이벤트 몇 개로만, 커리어 판단에 영향 주는 수준 |
| 연봉 표시 | 현실 숫자 (만 원 단위) |
| 확률 공개 | 숨김 — 결과를 보기 전까지 모름 |

연봉·자산은 평가 기준이 아니라 **보조 지표**(풍자 소재, 이직 판단용)로만 쓴다.

## 2. 핵심 루프 (1턴 = 1년)

```
[연초] 올해의 집중 선택 (1개)
   ↓
[연중] 자동 진행 → 능력치 성장, 프로젝트 성과 계산
   ↓
[이벤트] 랜덤 이벤트 1~2개, 각각 선택지 2~3개
   ↓
[연말] 인사고과(S/A/B/C/D) → 연봉 인상, 승진 심사
   ↓
[결과 화면] 수치 변화 + 커뮤니티 반응 피드
   ↓
[허브] 확인할 일: 이직 제안 / 승진 / 회사 소식 → 다음 해 or 은퇴
```

### 올해의 집중 (연초 선택)
| 선택 | 효과 |
|---|---|
| 업무에 올인 | 고과↑, 도메인↑, 체력↓↓ |
| 기술 공부 | 코딩·설계↑, 고과 보통 |
| 사이드 프로젝트 | 평판↑, 창업 플래그, 체력↓ |
| 네트워킹·발표 | 소통·평판↑, 이직 제안 확률↑ |
| 이직 준비 | 연말에 이직 제안 다수 |
| 쉬어가기 | 체력 회복, 성장 거의 없음 |

## 3. 캐릭터 생성 (4단계)

### ① 기본 정보
- 이름, 아바타
- **시작 나이**: 22~32세. 늦게 시작하면 소통·도메인 보너스

### ② 학력
| 학력 | 특징 |
|---|---|
| 명문대 컴공 | 대기업·빅테크 서류 통과율↑, 시작 능력치 균형 |
| 지방대 컴공 | 기본형, 중견·중소 진입 쉬움 |
| 비전공 | 코딩↓, 도메인·소통↑ |
| 부트캠프 | 코딩 실전형, 설계↓, 스타트업 진입 쉬움 |
| 고졸 독학 | 시작 능력치↓, 성장률↑ (대기만성형) |
| 해외대 | 외국계 진입 쉬움, 연봉 협상 보너스 |

### ③ 주력 분야 (kickru처럼 합은 같고 분포만 다름)
백엔드 / 프론트엔드 / 모바일 / 데이터·AI / 인프라·DevOps / 게임 클라이언트

후보 3개를 보여주고 1개 선택 → "집중 육성 능력치" 2개 선택.

### ④ 첫 회사 + 업종
학력·능력치에 따라 **합격 가능한 회사만** 선택지로 나온다 (서류 탈락 연출도 재미 요소).

## 4. 능력치

| 능력치 | 의미 | 주로 쓰이는 곳 |
|---|---|---|
| 코딩 | 구현 속도·품질 | 고과, 장애 대응 |
| 설계 | 아키텍처, 큰 그림 | 시니어 이상 승진 조건 |
| 소통 | 회의, 설득, 문서 | 리드·매니저 트랙 |
| 도메인 | 업종 이해도 | 같은 업종에 오래 있을수록↑, 이직하면 일부 리셋 |
| 평판 | 업계 인지도 | 이직 제안, 명성 점수 |
| 체력 | 0~100, 번아웃 게이지 | 0이 되면 강제 휴직 이벤트 |

보조 지표: 연봉, 자산, 나이, 연차.

## 5. 회사

### 규모별 특성 (1.0 = 기준)
| 유형 | 연봉 | 성장 | 야근 | 위험 | 승진 속도 | 패러디 예시 |
|---|---|---|---|---|---|---|
| 대기업 본사 | 1.4 | 0.8 | 보통 | 매우 낮음 | 느림 | 삼선전자 |
| 대기업 SI 계열사 | 1.2 | 0.7 | 높음 | 낮음 | 느림 | 엘쥐씨엔에스 |
| 국내 빅테크 | 1.5 | 1.2 | 보통 | 낮음 | 보통 | 네모버, 까까오, 쿠팽, 토스트 |
| 외국계 | 1.6 | 1.0 | 낮음 | 중간(본사 감원) | 보통 | 구글리, 아마존강 |
| 중견 | 1.0 | 0.9 | 보통 | 낮음 | 보통 | — |
| 중소 SI·SM | 0.8 | 0.8 | 매우 높음 | 중간 | 빠름 | — |
| 외주 에이전시 | 0.8 | 1.1 | 매우 높음 | 높음 | 빠름 | — |
| 시드 스타트업 | 0.7 + 스톡옵션 | 1.4 | 높음 | 매우 높음 | 매우 빠름 | — |
| 시리즈B 스타트업 | 1.0 + 스톡옵션 | 1.2 | 높음 | 높음 | 빠름 | — |
| 유니콘 | 1.3 + 스톡옵션 | 1.1 | 보통 | 중간 | 보통 | — |
| 금융권·공공 IT | 1.1 | 0.6 | 낮음 | 매우 낮음 | 연차순 | 국밍은행 |

**위험** = 연 단위로 폐업·구조조정·인수가 일어날 확률.

### 연봉 (현실 숫자, 게임 밸런스용 대략치)
| 유형 | 신입 초봉 |
|---|---|
| 외국계 | 6,000만 |
| 국내 빅테크 | 5,800만 |
| 대기업 본사 | 5,500만 |
| 유니콘 | 5,000만 + 스톡옵션 |
| 금융권·공공 IT | 5,000만 |
| 대기업 SI 계열사 | 4,600만 |
| 중견 | 4,000만 |
| 시리즈B 스타트업 | 4,000만 + 스톡옵션 |
| 중소 SI·SM | 3,200만 |
| 외주 에이전시 | 3,000만 |
| 시드 스타트업 | 3,000만 + 스톡옵션 |

- 연말 인상률: S +12% / A +8% / B +4% / C +1% / D 동결
- 승진 시 +5~10%, 이직 시 +10~30% (평판·협상 이벤트로 변동)
- 연봉은 블라인더 "연봉 인증" 반응, 이직 제안 비교 화면에 쓴다
- 실제 시장과 다르다는 논쟁을 피하려고 화면 하단에 "게임용 가상 수치" 문구
스타트업은 매년 투자 유치·폐업·엑싯 판정이 있고, 엑싯하면 스톡옵션이 터진다.

### 업종
| 업종 | 효과 |
|---|---|
| SI/SM | 야근↑, 도메인 쌓기 쉬움, "갑을" 이벤트 |
| B2B SaaS | 안정적, 설계 성장↑ |
| B2C 플랫폼 | 트래픽 장애 이벤트↑, 평판↑ |
| 커머스 | 블프·명절 대란 이벤트 |
| 핀테크·금융 | 규제·보안 감사 이벤트, 연봉↑ |
| 게임 | 크런치 모드, 출시 대박/폭망 |
| AI | 고연봉·고위험, 연차가 쌓일수록 주가 변동 큼 |
| 공공 | 안정, 성장↓, "나라장터" 이벤트 |

## 6. 직급과 진로

```
신입 → 주니어 → 미들 → 시니어 → 리드
                                   ├─ 매니저 트랙: EM → 디렉터 → VP → CTO
                                   ├─ IC 트랙: 스태프 → 프린시펄 → 펠로우
                                   └─ 이탈: 창업 / 프리랜서 / 강사·유튜버 / 공무원 / 치킨집
```

- 승진 조건 = 연차 + 능력치 기준 + 최근 고과 (회사 유형마다 기준이 다름)
  - 고과별 승진 확률 S 90% / A 70% / B 30%, 리드 위로는 자리가 적어 절반
  - 정확한 직급별 기준은 `src/data/career.ts`
- 연봉 상한: 시장 연봉(회사·업종·직급·연차 기준)의 1.3배를 넘으면 인상 폭이 30%로 줄고, 이직 제안은 시장 연봉의 1.5배를 넘지 않는다
- 리드에서 트랙을 고른다 (전환점 이벤트)
- 창업은 사이드 프로젝트 플래그가 있으면 열리고, 이후 매년 생존 판정

## 7. 이벤트

### 카테고리와 예시
| 카테고리 | 예시 |
|---|---|
| 장애 | 금요일 18시 배포 후 장애 / 새벽 3시 DB 락 / 블프 트래픽 폭주 |
| 레거시 | 주석 없는 20년 된 코드 / "건드리지 마시오" 모듈 / 전임자 퇴사 |
| 일정 | 기획 변경 D-3 / "간단한 거니까 내일까지" / 오픈일 고정 |
| 사람 | 꼰대 PM / 천재 신입 / 코드리뷰 전쟁 / 팀장 퇴사 |
| 커리어 | 헤드헌터 연락 / 카운터 오퍼 / 스톡옵션 vs 연봉 |
| 회사 | 투자 유치 / 인수합병 / 권고사직 / 사옥 이전 |
| 업계 | AI가 내 업무 자동화 / 신기술 유행 / 개발자 채용 한파 |
| 개인 | 기술 블로그 바이럴 / 오픈소스 PR 머지 / 컨퍼런스 발표 요청 |

### 개인 생활 (가볍게)
별도 시스템 없이 이벤트 몇 개 + 플래그로만 처리한다.

| 이벤트 | 결과 플래그 | 커리어에 미치는 영향 |
|---|---|---|
| 결혼 | `married` | 자산↓, 체력 회복량↑, 고위험 선택(창업·스타트업 이직) 망설임 이벤트 |
| 출산 | `hasChild` | 육아휴직 선택지 — 회사 유형별 눈치 정도가 다름 |
| 주택 대출 | `mortgage` | 몇 년간 연봉 하락 이직·창업 선택 시 경고 |
| 부모님 병환 | — | 1년간 체력↓, 휴직 선택지 |

### 확률 숨김 원칙
- 선택지 결과 확률은 화면에 표시하지 않는다
- 능력치 조건(`requires`)은 보여준다: "소통 40 필요" — 조건 미달이면 선택지 비활성화
- 결과 텍스트에서 운인지 실력인지 슬쩍 드러낸다: "운이 좋았다" / "실력으로 막았다"

### 시대 흐름
게임 내 연도가 지날수록 **AI 자동화 압력**이 커진다. 주니어 채용 감소, 단순 코딩 가치 하락, 설계·도메인 가치 상승. 후반부 전략이 달라지게 만드는 장치.

### 데이터 형식 (콘텐츠는 이 형식으로 계속 추가)
실제 파일은 `src/data/events.ts`의 타입 붙은 배열이다(`GameEvent`, 정의는 `src/engine/types.ts`). 아래는 구조 설명용 JSON.
```json
{
  "id": "friday_deploy",
  "category": "장애",
  "title": "금요일 18시 배포",
  "text": "팀장이 '간단한 거니까 지금 배포하고 퇴근하자'고 한다.",
  "conditions": { "minYear": 1, "companyTypes": ["*"] },
  "weight": 10,
  "choices": [
    {
      "label": "그냥 배포한다",
      "outcomes": [
        { "chance": 0.6, "effects": { "stamina": 0 }, "text": "무사히 퇴근했다." },
        { "chance": 0.4, "effects": { "stamina": -20, "reputation": -3 }, "text": "주말 내내 롤백했다.", "achievement": "weekend_rollback" }

```

## 9. 엔딩과 평가

### 은퇴 조건
- 60세 도달 / 자진 은퇴 / 번아웃 3회 누적 / 창업 실패 후 재기 포기

### 명성 점수 = 최고 직책 점수 + 평판×0.5 + 업적 점수
등급 기준: S 130 / A 95 / B 65 / C 35 이상 / 그 아래 D
| 등급 | 칭호 예시 |
|---|---|
| S | 한국 IT의 전설 |
| A | 업계가 아는 이름 |
| B | 믿고 맡기는 시니어 |
| C | 무난한 월급쟁이 |
| D | 치킨집 사장님 |

### 업적 예시
- 주말 롤백 (금요일 배포로 주말 반납)
- 레거시 고고학자 (10년 넘은 코드 3번 리팩토링)
- 이직의 신 (5회 이상 이직)
- 한 우물 (한 회사 20년)
- 스톡옵션 로또 (엑싯 성공)
- 스톡옵션 휴지 (폐업 3회)
- 새벽 3시의 남자/여자 (장애 대응 10회)
- 비전공 CTO (비전공 시작으로 CTO 도달)
- 오픈소스 스타 (평판 90 이상)
- 무사고 퇴직 (번아웃 0회로 60세 은퇴)
- AI에게 일자리 뺏김
- 공무원 엔딩

## 11. 기술 방향

- Vite + React + TypeScript, 상태 관리 Zustand, 스타일 Tailwind
- **시뮬레이션은 순수 TS 함수로 분리** (`simulateYear(state, choice, rng) → newState`), UI와 독립적으로 테스트
- 이벤트·회사·반응 템플릿은 `src/data/*.ts` (JSON 대신 TS — 오타·잘못된 ID를 빌드에서 잡기 위해), 무결성은 `src/data/data.test.ts`가 검사
- 시드 기반 랜덤 → 같은 시드면 같은 결과 (버그 재현, 공유용)
- 배포: Cloudflare Pages
